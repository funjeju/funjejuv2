
# PRODUCT.md

## 제품 정의

본 서비스는 제주 실시간 데이터와 AI를 결합한 여행 플랫폼이다.

사용자는 실시간 제주 상황을 탐색하고, 장소를 저장하며, AI 여행 일정을 만들고, 여행 후 기록을 다시 콘텐츠로 전환할 수 있다.

핵심은 실시간성, 여행 기록, AI 자동화다.

## 제품 목표

제주 여행 정보를 검색하는 서비스를 만드는 것이 아니다.

실시간 제주를 발견하고, 저장하고, 여행을 설계하는 플랫폼을 만든다.

핵심 목표:

* 실시간 제주 탐색
* 여행 의사결정 지원
* 여행 기록 자산화
* 일정 생성 자동화
* 콘텐츠 자동 생산

## 사용자 가치

사용자는 제주 여행을 더 쉽게 결정할 수 있어야 한다.

제공 가치:

* 지금 제주 분위기 확인
* 실제 여행 데이터 탐색
* 장소 저장
