# USER_FLOW.md

## 문서 목적

사용자 행동 흐름과 화면 이동 구조를 정의한다.

목표:

* 사용자 행동 흐름 정의
* 화면 이동 기준 정의
* 저장 및 생성 흐름 정의
* 관리자 운영 흐름 정의

---

## 1. 일반 사용자 메인 흐름

### 흐름

홈 진입 → 제주 탐색 → 장소 저장 → AI 일정 생성 → 여행 → 기록 → 콘텐츠 재생산

---

## 2. CCTV 탐색 흐름

### 흐름

홈 → CCTV → 목록형 또는 지도형 → CCTV 상세 → 채팅 참여 → 장소 저장 → 일정 추가

### 행동

사용자는 실시간 제주 상황을 탐색한다.

행동:

* CCTV 보기
* 지역 탐색
* 채팅 참여
* 장소 저장
* 공유

---

## 3. EXIF 라이브 피드 흐름

### 흐름

사진 업로드 → EXIF 분석 → OCR 분석 → AI 감성 멘트 생성 → 카드뉴스 생성 → 공개 설정 → 피드 발행

### 행동

사용자는 여행 기록을 업로드한다.

행동:

* 사진 업로드
* 공개 여부 설정
* 장소 저장
* 일정 연결

---

## 4. 유튜브 요약 흐름

### 흐름

영상 선택 → AI 요약 → 스팟 추출 → 장소 저장 → 일정 추가

### 행동

사용자는 영상 기반 장소를 수집한다.

행동:

* 영상 보기
* 장소 저장
* 일정 연결

---

## 5. 여행 스팟 저장 흐름

### 흐름

콘텐츠 탐색 → 저장 버튼 → 마이페이지 저장 → 일정 추가

### 저장 출처

* CCTV
* 라이브 피드
* 유튜브 요약
* AI 추천
* 검색

---

## 6. AI 여행 일정 생성 흐름

### 흐름

일정 생성 시작 → 질문 응답 → 저장 장소 불러오기 → AI 일정 생성 → 수정 → 저장 → 공개 여부 설정

### 행동

사용자는 여행 조건을 입력한다.

입력:

* 기간
* 이동 방식
* 동행 유형
* 취향
* 저장 장소

---

## 7. 공개 일정 탐색 흐름

### 흐름

AI 여행 일정 → 공개 일정 탐색 → 일정 상세 → 찜 → 복사 → 수정 → 저장

### 행동

사용자는 다른 사람의 여행 일정을 활용할 수 있다.

---

## 8. 비즈니스 계정 흐름

### 흐름

회원가입 → 비즈니스 인증 → CTA 등록 → 피드 업로드 → 자동 CTA 연결

### 행동

사업자는 피드와 장소를 연결한다.

---

## 9. 관리자 흐름

### 흐름

관리자 로그인 → 운영 대시보드 → 데이터 관리 → 승인/수정/삭제

### CCTV 관리 흐름

관리자 → CCTV 관리 → 등록/수정 → 노출 설정

### 스팟 관리 흐름

관리자 → 스팟 관리 → 수정 → 태그 관리 → 노출 설정

### 회원 관리 흐름

관리자 → 회원 관리 → 권한 변경 → 비즈니스 승인 → 신고 처리

### 피드 관리 흐름

관리자 → 피드 관리 → 신고 처리 → 삭제 → 추천 노출 설정

### SEO 콘텐츠 흐름

관리자 → SEO 콘텐츠 → 수정 → 승인 → 발행

### 채팅 관리 흐름

관리자 → 채팅 관리 → 신고 처리 → 제한 → 삭제
