# FEATURE_SPEC.md

## 문서 목적

본 문서는 기능 단위 구현 명세를 정의한다.

목표:

* 기능 누락 방지
* 화면/DB/API 연결 기준 제공
* 바이브 에이전트 구현 기준 제공

기능은 메뉴 단위로 정의한다.

## 1. CCTV 허브

### 기능 정의

제주 CCTV를 한곳에서 탐색하는 기능이다.

### 화면 구성

구성:

* 목록형 보기
* 지도형 보기
* CCTV 상세 보기
* 즐겨찾기
* 공유
* CCTV 채팅
* 제주 통합 채팅
* AI 상황 요약

### 목록형

설명:
카드 리스트 방식으로 CCTV를 탐색한다.

데이터:

* 썸네일
* 지역명
* 카테고리
* 상태
* 즐겨찾기 여부

행동:

* 클릭 시 상세 진입
* 찜 가능

### 지도형

설명:
지도 위 CCTV 위치를 시각화한다.

데이터:

* 좌표
* 지역명
* 썸네일

행동:

* 지도 이동
* CCTV 선택
* 상세 이동

### CCTV 상세

설명:
선택한 CCTV 정보를 보여준다.

구성:

* 영상
* 지역 정보
* 날씨 정보
* 채팅
* 저장 버튼
* 추천 스팟

행동:

* 장소 저장
* 공유
* 채팅 참여

### CCTV별 채팅

설명:
각 CCTV별 실시간 채팅방.

기능:

* 실시간 메시지
* 좋아요
* 신고
* AI 요약

예:
“함덕 노을 좋음”
“바람 강함”

### 제주 통합 채팅

설명:
제주 전체 공용 채팅.

기능:

* 실시간 대화
* 인기 주제
* 여행 질문
* AI 요약
