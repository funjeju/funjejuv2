## 1. 왜 논짓물은 funjeju에선 나오고 시청 홈페이지에선 안 나오나

| | 서귀포시 홈페이지 | funjeju.com |
|---|---|---|
| 영상 서버 | 새 서버 `211.34.191.218` / `.219` (G-STREAMER 3.5.5) | 예전 서버 `211.34.191.215:1935` (Wowza 방식 경로) |
| 주소 형태 | `/live/10010/playlist.m3u8?uid=<토큰>` | `/live/1-193.stream/playlist.m3u8` |
| 인증 | 접속마다 `hlsStreamUrl.jsp`가 uid 토큰 발급 | 토큰 없음 |
| 현재 상태 | 토큰을 받자마자 써도 `-401 Expired` / `-404 Not Found` | 정상 재생 |

- 시청은 새 서버로 옮겼고, 새 서버의 토큰 인증이 고장 난 상태입니다. 토큰 발급 서버 시계가 영상 서버보다 약 6분 30초 빠른 것을 측정했고, 이것이 원인일 가능성이 있습니다(추정).
- 예전 서버는 꺼지지 않고 계속 송출 중입니다. 2026-11-04 10시경 funjeju에 등록된 서귀포 예전 서버 주소 17개를 모두 확인했고 전부 `#EXTM3U` 응답이 왔습니다.
- **그래서 예전 서버 주소를 알고 있는 카메라는 funjeju에서 계속 나올 수 있습니다.** 다만 시청이 언제든 예전 서버를 끌 수 있으니, 끊기면 바로 알 수 있게 `scripts/probe-cctv.mjs` 같은 점검에 포함시키는 것을 권합니다.

## 3. C 그룹을 funjeju에 넣는 방법

예전 서버에서 응답은 하지만 이름이 없는 스트림이 있습니다(10시 스캔, 일부 누락 가능):
`1-32, 1-61, 1-81, 1-82, 1-84, 1-197, 1-200, 11-21, 11-22, 11-51 ~ 11-57` (+ 예전 목록의 `22`=중문포구, `61`=전포천)

- `11-51 ~ 11-57` 7대가 연번이라 새로 생긴 대정·마라도 쪽 월파 카메라일 가능성이 있습니다(추정).
- **`scripts/output/seogwipo-old-stream-preview.html`을 PC에서 더블클릭**하면 위 스트림이 한 화면에 뜹니다. 화면을 보고 C 표의 장소와 짝지으면 됩니다. (제 쪽 브라우저 확장으로는 영상 화면을 캡처하지 못해 짝짓기는 못 했습니다.)

## 4. 적용 체크리스트 (`lib/sky/cameras.ts`)

- [ ] 짝지은 카메라를 `SKY_CAMERAS`에 `group: "S"`, `source: { kind: "http", url: "http://211.34.191.215:1935/live/<스트림>.stream/playlist.m3u8" }`로 추가
- [ ] `x, y` 계산: 주소 → 위·경도(카카오 로컬 API 등) → `lib/sky/outline.ts`와 같은 투영으로 % 환산. 세천포구 주석과 같은 방식
- [ ] 겹치는 자리 1~2% 벌리기: 태흥 3대(10005·10037·10038), 신산 2대(10004·10036), 무릉 2대(10034·10035), 마라도 2대(10028·10029) — 마라도는 추자도처럼 지도 밖 상자로 빼는 것도 방법
- [ ] `label`은 대표 1대만 true, `thumb`는 `public/sky/cams/{id}.jpg` 캡처 후 true
- [ ] 파일 맨 위 주석 "53대" 숫자, 헤더 "53 CAMERAS ON AIR" 숫자가 배열 길이에서 나오는지 확인
- [ ] 시청 새 서버(218/219) 주소는 쓰지 말 것: 토큰이 필요하고 지금 고장 상태
- [ ] **HTTP 뷰어 확인:** `http://cctv-view.funjeju.com/?src=...`가 지금 `404: NOT_FOUND`(Vercel)로 뜹니다. `NEXT_PUBLIC_HTTP_VIEWER_URL`이 설정되어 있다면 서귀포 카메라 새 창이 깨지고, 설정이 없다면 Vultr 뷰어로 열립니다. `http-viewer/README.md`의 GitHub Pages 설정(3~5번)이 끝났는지 확인 필요
