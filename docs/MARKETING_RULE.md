# MARKETING_RULE.md

## 문서 목적

서비스 성장 구조와 콘텐츠 운영 규칙을 정의한다.

목표:

* 자연 유입 구조 설계
* SEO 자동화
* 콘텐츠 재생산
* 사용자 생성 데이터 활용

원칙:
Paid 중심이 아닌 Organic 중심 성장.

---

## 성장 구조

서비스는 다음 구조로 성장한다.

실시간 데이터
→ 콘텐츠 생성
→ 검색 유입
→ 사용자 저장
→ 일정 생성
→ 사용자 업로드
→ 콘텐츠 재생산

핵심:
콘텐츠 순환 구조.

---

## 핵심 유입 채널

유입 채널:

* SEO
* 유튜브 검색
* SNS 공유
* 사용자 공유
* 지역 키워드 검색
* 피드 링크 공유

---

## SEO 전략

목표:
제주 롱테일 키워드 선점.

콘텐츠 소스:

* EXIF 라이브 피드
* CCTV 데이터
* 유튜브 요약
* 일정 데이터
* 사용자 기록

예:

* 제주 노을 명소
* 오늘 제주 날씨 여행
* 제주 비 오는 날 코스
* 제주 CCTV 실시간

원칙:
실시간성과 지역성 우선.

---

## SEO 콘텐츠 규칙

구성:

* 제목
* 서브타이틀
* 목차
* 이미지
* 장소 정보
* FAQ

원칙:
검색 의도 기반 작성.

금지:

* 키워드 남발
* 의미 없는 반복
* 클릭베이트

---

## 사용자 생성 콘텐츠(UGC)

목표:
피드 기반 콘텐츠 증가.

유도:

* 사진 업로드
* 공개 피드
* 일정 공개
* 장소 저장 공유

원칙:
업로드 장벽 최소화.

---

## EXIF 피드 성장 전략

피드는 콘텐츠 자산 역할을 한다.

목표:

* 실시간 제주 기록 축적
* 검색 유입 증가
* SNS 공유 증가

구성:

* 감성 카드뉴스
* CTA
* 장소 저장
* 일정 연결

---

## 유튜브 성장 전략

유튜브 여행 영상을 재해석한다.

목표:

* 검색 유입
* 장소 저장 증가
* 일정 생성 증가

구성:

* 여행 요약
* 장소 추출
* 저장 CTA

---

## AI 일정 성장 전략

공개 일정은 검색 자산 역할을 한다.

예:

* 부모님 제주 2박3일
* 혼자 감성 제주
* 아이와 우천 여행

기능:

* 공유
* 찜
* 복사

---

## SNS 공유 전략

공유 대상:

* 피드 카드
* 일정 카드
* 장소 카드
* CCTV 카드

원칙:
이미지 중심 공유.

---

## 비즈니스 성장 전략

비즈니스는 광고보다 자연 노출 중심.

방식:

* 피드 CTA
* 장소 연결
* 실시간 참여
* 공개 일정 연결

금지:

* 광고 도배
* 과도한 홍보

---

## KPI 기준

지표:

* 저장 수
* 일정 생성 수
* 공개 일정 수
* 피드 업로드 수
* SEO 유입 수
* 재방문율
* 공유 수

핵심 KPI:
저장 → 일정 생성 전환율

---

## 운영 원칙

원칙:

* 콘텐츠 중심 성장
* 실시간 데이터 중심
* SEO 우선
* 사용자 행동 데이터 활용
* 공유 가능한 콘텐츠 생산
