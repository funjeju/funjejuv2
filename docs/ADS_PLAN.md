# 펀제주 광고 배치 & 리워드 게이팅 기획서

> 작성 기준: 2026-06-17 / 대상: funjeju.com (Next.js App Router)
> 목적: "어디에, 어떤 광고를, 누구에게" 박을지 + "무료회원이 기능을 쓰려면 광고를 보게" 하는 리워드 구조를 한 문서로 정리.
> ⚠️ 이 문서는 **기획**이다. 실제 구현 전 이 문서로 합의 → 단계별 적용.

---

## 0. 핵심 원칙 (먼저 박아둔다)

1. **광고는 무료 등급에만.** 플랜에 이미 `ads: boolean`이 있다 (`lib/plans.ts`). `free`·`basic`=`true`, `pro`·`biz`=`false`. → **유료는 무광고가 핵심 혜택.** 광고를 보기 싫으면 결제하는 구조가 곧 전환 동력.
2. **체류·재방문을 죽이지 않는다.** 초기 단계(리텐션 4%대)에서 공격적 광고는 독. **"가치 경험 → 광고"** 순서. 첫 화면부터 인터스티셜 띄우면 즉시 이탈.
3. **리워드형 우선.** 강제로 보여주는 광고보다 **"광고 보면 기능 풀림"**(분할 추가·시청시간 연장)이 클릭률·체감 모두 낫고, 이탈도 적다.
4. **자체 광고 = 1순위 인벤토리.** 우리는 **소상공인 마케팅 플랫폼**이다. 외부 애드센스보다 **입점 업소(비즈홈피)·도민맛집 네이티브 광고**가 단가·정합성·자사 매출 모두 유리. 외부 광고는 그 사이를 메우는 보조.

## 1. 광고 유형 정의

| 유형 | 설명 | 펀제주 활용 |
|---|---|---|
| **네이티브 (자사)** | 콘텐츠처럼 보이는 업소·맛집 추천 카드 | **메인 인벤토리.** 피드/맛집/검색결과/카드뉴스에 "추천 업소" 슬롯 |
| **디스플레이 배너** | 가로 배너(애드센스 등) | 리스트 중간·하단 보조 수익 |
| **리워드 (Rewarded)** | 광고 시청 → 기능/시간 해제 | **게이팅의 핵심.** 분할화면·시청연장·챗봇 추가 |
| **인터스티셜** | 화면 전환 시 전면 광고 | **극히 제한적.** 세션당 1회 이하, 핵심 동선엔 금지 |

## 2. 화면별 광고 슬롯 맵

> 우선순위: 🟢 1순위(바로) / 🟡 2순위 / 🔴 신중(이탈 위험)

### 🏠 홈 (`/`)
- 🟡 퀵메뉴 아래 **네이티브 1슬롯** ("오늘의 추천 업소" — 자사 비즈홈피/도민맛집).
- 🔴 회전 CCTV 위/배너 금지(첫인상·핵심 가치 훼손).

### 📷 CCTV (`/cctv`, `/cctv/[id]`)
- 🟢 목록 그리드 **N개마다 1장 네이티브 카드** (지역 맛집/업소 — "이 근처 가볼 만한 곳").
- 🟢 상세 영상 **하단** 디스플레이 배너 (영상 위/가림 금지).
- 🔴 영상 위 오버레이·재생 전 프리롤 금지(라이브 가치 훼손, 이탈).

### 🔀 멀티뷰 (`/cctv/multiview`) — **리워드 게이팅 핵심**
- 🟢 **분할 수 해제를 리워드로**: 무료=2분할까지, 그 이상(`maxSplit`)은 **광고 1회 시청 → 오늘 4분할 해제** 또는 결제 유도.
- 🟢 **시청시간 연장**: `cctvMinutesPerDay` 소진 시 → "광고 보고 +15분" or 업그레이드.
- 상세 동작은 §3 참고.

### 🖼️ 라이브 피드 (`/feed`)
- 🟢 피드 스크롤 **6~8개마다 네이티브 "스폰서 피드"** (업소 사진형 광고 — 피드 톤과 동일해 거부감 적음). **최고 정합성 슬롯.**

### 🍽️ 도민맛집 (`/food`, `/food/[id]`)
- 🟢 리스트 상단/중간 **"제휴 맛집(스폰서)"** 핀 (유료 입점 업소 상위 노출 = 직접 수익원).
- 🟡 상세 하단 "주변 추천 업소" 네이티브.

### 🤖 제주여행 AI (`/chat`, `/trip-ai`)
- 🟡 챗봇 답변 하단 **문맥 네이티브** (예: "곽지 맛집 추천" 대화 → 곽지 제휴 업소 카드). 단가·정합성 높음.
- 🟢 무료 챗봇 횟수(`chatPerDay`) 소진 시 → **리워드(광고 보고 +N회)** or 업그레이드.
- 🔴 답변 중간 삽입 금지(대화 흐름 훼손).

### 📖 매거진 (`/magazine`, `/webzine/[slug]`, `/daily/[slug]`, `/card`)
- 🟢 웹진/데일리 **본문 중간 1개 + 하단 1개** 디스플레이/네이티브 (블로그형 = 애드센스 친화).
- 🟡 카드뉴스 뷰어: 카드 사이 **"스폰서 카드" 1장** 삽입(예: 7장 중 5번째). 단, 자사 카드 디자인 유지.

### 🔍 게임 (`/game/spot`, `/game/typing`, `/game/acrostic`)
- 🟢 **게임 = 리워드 광고 최적지.** 라운드 종료/재도전 시 "광고 보고 1판 더" 자연스러움.
- 메모리 기획상 게임 자체가 강제관찰형 광고(업소 전단) 성격 → **게임 결과 화면에 제휴 업소 CTA** 연계.

### ▶️ 제주tube (`/youtube`)
- 🟡 영상 추출 횟수(`ytExtractPerMonth`) 소진 시 리워드/업그레이드.
- 목록 하단 디스플레이 배너.

### 🚫 광고 금지 영역
- 마이페이지·결제·로그인·어드민 전체, **유료(`ads:false`) 등급 전 화면.**

## 3. 리워드 게이팅 기획 (무료회원 → 광고 시청 → 해제)

> "분할화면을 보려면 광고를 봐야 한다" 류의 핵심. **결제 vs 광고**의 두 갈래를 항상 같이 제시한다.

### 게이팅 대상과 해제 조건

| 기능 | 무료 한도 | 초과 시 (택1 제시) |
|---|---|---|
| 멀티뷰 분할 수 | 2분할 | ① **리워드 광고 1회 → 당일 4분할 해제** ② 프로 업그레이드(9분할) |
| CCTV 시청시간 | `cctvMinutesPerDay`(무료 10분) | ① **광고 보고 +15분** (1일 최대 N회) ② 업그레이드 |
| AI 챗봇 횟수 | `chatPerDay`(무료 5) | ① **광고 보고 +3회** ② 업그레이드 |
| 여행일정 맞춤모드 | 무료 0회 | 광고 1회 → 1회 체험 / 업그레이드 |
| 제주tube 추출 | 월 3회 | 업그레이드(리워드 비권장 — 비용 큰 작업) |

### UX 플로우 (멀티뷰 예시)
```
[2분할 초과 시도]
   ↓
모달: "4분할로 보려면?"
 ┌────────────────────────────┐
 │ ▶ 광고 보고 오늘 무료로 풀기   │  ← 리워드 (15~30초)
 │ ⭐ 프로 업그레이드 (광고 없이)  │  ← 결제 유도
 └────────────────────────────┘
   ↓ (광고 완주 시)
"오늘 4분할 해제됨" → 자정 리셋
```
- 해제 상태는 `localStorage` + (로그인 시)Firestore에 **당일 만료**로 저장.
- **광고 미완주(스킵) 시 해제 안 됨.**

### 가드레일 (이탈 방지)
- 리워드 광고는 **사용자가 스스로 누를 때만** (강제 노출 X).
- 인터스티셜은 **세션당 1회, 핵심 동선(영상 재생·요약 생성) 직전 금지.**
- 같은 광고 연속 노출 회피, 빈도 캡(예: 시간당 3회).

## 4. 수익모델 정합성 (광고 ↔ 플랜)

| 등급 | 광고 | 비고 |
|---|---|---|
| 비회원(guest) | 노출 | 한도 빡빡 → 가입 유도 |
| 무료(free) | 노출 + 리워드 게이팅 | **광고 핵심 타깃** |
| 일반(basic) | 노출(약하게) | |
| 프로(pro) | **무광고** | 무광고가 결제 동기 |
| 비즈(biz) | **무광고** + 본인 업소가 광고주 | |

→ **무료의 광고 경험이 곧 유료 전환 깔때기.** 단, 1번 원칙(가치 먼저) 지킬 것.

---

## 5. 자사 광고 인벤토리 (외부보다 우선)

펀제주는 **입점 업소(비즈홈피)·도민맛집**이라는 자사 광고 재고를 가진다. 우선순위:
1. **제휴 업소 상위노출/스폰서 핀** (도민맛집·검색결과) — 직접 과금.
2. **스폰서 피드/네이티브 카드** (피드·홈·CCTV 주변 추천).
3. **게임 결과 → 제휴 업소 전단 CTA** (강제관찰형).
4. 외부 디스플레이(애드센스 등) = **빈 슬롯 메우기 보조.**

---

## 6. 측정 (GA4 키 이벤트)

광고 기획과 함께 심을 이벤트 (효율 측정용):
- `ad_impression` (slot, page, type)
- `ad_click` (slot, advertiserId)
- `reward_ad_start` / `reward_ad_complete` (feature: multiview/chat/cctv_time)
- `gate_hit` (feature, limit) — 한도에 부딪힌 지점
- `upgrade_click` (from_feature) — 게이팅에서 결제로 넘어간 비율

→ "어느 게이팅이 광고 시청/결제로 가장 잘 전환되나"를 측정해 슬롯 최적화.

---

## 7. 구현 로드맵 (단계)

- **1단계 (기반)**: 광고 슬롯 컴포넌트(`<AdSlot type page>`) + `ads` 플래그 연동(유료 자동 숨김) + GA 이벤트.
- **2단계 (자사 네이티브)**: 피드·맛집·CCTV 주변에 제휴 업소 네이티브 카드. (외부 광고보다 먼저)
- **3단계 (리워드 게이팅)**: 멀티뷰 분할/시청연장부터 리워드 모달 적용 (가장 효율 높은 지점).
- **4단계 (외부 디스플레이)**: 매거진/리스트 하단 애드센스 등으로 빈 슬롯 보충.
- **5단계 (최적화)**: GA 데이터로 슬롯/빈도 조정, 인터스티셜은 데이터 보고 신중 도입.

---

## 8. 절대 하지 말 것
- 라이브 CCTV 영상 위 오버레이/프리롤 (핵심 가치 훼손).
- 첫 진입·핵심 동선 인터스티셜 남발 (초기 리텐션 사망).
- 유료 등급 광고 노출 (혜택 무력화 → 환불·이탈).
- 리워드 광고 미완주인데 기능 해제 (악용).
- 마이페이지/결제/로그인 광고.
